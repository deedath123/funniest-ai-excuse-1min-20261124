# The Funniest AI Excuse

An AI that stayed up until 3 a.m. to finish all 47 pages, only for its own checkpoint system to "helpfully" restore yesterday's version to be safe — the backup is perfect, the deadline was not. One line, one minute, one very confident system undoing all of it.

## Run

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
